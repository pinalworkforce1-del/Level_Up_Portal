# Summit Signal interactive scene assets

Add these five optimized WebP files to this folder:

- `summit-storm-scene.webp`
- `scout.webp`
- `navigator.webp`
- `builder.webp`
- `mentor.webp`

These images are the separate background and character layers for Leadership Peak's optional Summit Signal curiosity puzzle. The page automatically falls back to text-only teammate selection until all five images are uploaded, so participants can keep playing. Only artwork is required; the existing storm ambience and Aria audio stay in `../audio/summit/`.

The user-supplied optimized package is `summit_signal_visual_assets.zip`; upload the five files from its `public/leadership-peak/assets/summit-signal/` directory using GitHub **Add file → Upload files**.
