Summit Signal — Level Up audio package

Upload these assets to the GitHub repository pinalworkforce1-del/Level_Up_Portal
inside public/leadership-peak/assets/audio/summit/

This archive contains six MP3 files plus the five matching caption VTT files.
The VTT files were also added directly to the repository, so GitHub may show
them as existing — overwrite those only if necessary.

HOW TO UPLOAD
1. Extract this ZIP on your computer.
2. Open the Level_Up_Portal repository in GitHub.
3. Navigate to public/leadership-peak/assets/audio/summit/
4. Choose Add file > Upload files and drag in the six summit_*.mp3 files.
5. Commit directly to main (or your normal review workflow).
6. Wait for GitHub Pages to deploy and then open the Leadership Peak summit.
7. Click Play Scenario, turn on Storm ambience, request a hint, and solve the puzzle.

The site already expects these relative asset paths. No credentials, API keys,
or Supabase changes are needed. Keep voice tracks and ambience optional;
the full puzzle works without audio.
